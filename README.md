# UMAST レポート

競馬のレース結果レポートを静的HTMLで公開しています。

**公開URL: https://ulysse.github.io/umast-reports/**

## 中身

- `index.html` — レポート一覧
- `reports/<年>/<日付>_<競馬場>.html` — 開催ごとのレポート

各レポートは単一HTMLで完結しており、外部のCSS・JS・画像・CDNに一切依存しません。
ブラウザで開くだけで動き、オフラインでも表示できます。

## 収録内容

- 全レースの結果一覧（勝ちタイム / 平均タイム比 / 前後半差 / 上り3F / 4角通過順）
- 馬場読み（PBI・Δ前後半差・前半3F/上り3Fの平年比・馬場判定）
- ラップ推移、3区間ラップの平年比
- 散布図（着差×上り3F / 着差×馬番 / 4コーナー順位×上り3F / 距離×上り3F）
- レースごとの全出走馬・ラップ・コーナー通過順・払戻

グラフは凡例クリックで表示を切り替えられ、点にカーソルを合わせると数値が出ます。
右上のボタンでライト／ダーク表示を切り替えられます。

## このリポジトリについて

公開してよい成果物（HTML）だけを置くための専用リポジトリです。
解析ソースコード・データベース・研究記録は別の非公開環境にあり、ここには含まれません。
`.gitignore` はホワイトリスト方式（全無視 → HTMLのみ許可）にしてあり、
それらが誤って混入しないようにしています。
